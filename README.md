# Minecraft-Backpack
《我的世界背包》是一个照着《我的世界》原版物品栏做的桌面快捷启动器。界面左边是会慢慢转身的角色皮肤，中间是 3 行 × 9 列的背包网格，最下面那行是 9 格快捷栏——把常用软件拖进去，按数字键就能一键打开，装不下的自动翻到下一页，最多 9 页 243 格。程序只有一个 exe，双击即用、无需安装，配置和图标都存在本地，换电脑拷走就能继续用。 介绍稍全版（约 200 字，适合放到说明开头） 《我的世界背包》把 Windows 桌面变成一个游戏背包：桌面和开始菜单里的程序一次性扫进"背包"，常用的拖到最下面那行"快捷栏"，之后按数字键 1~9 直接启动，不用再满桌面找图标。
